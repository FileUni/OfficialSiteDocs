# 管理者パスワードのリセット

組み込み管理者パスワードを紛失した場合は、明示的な管理者リセット操作を使用します。

## 回復手順

1. 実行中の FileUni サービスまたはデスクトップインスタンスを停止します。
2. ランタイムディレクトリを確認します。
3. CLI の管理者リセットを実行するか、GUI ランチャーの管理者パスワード変更アクションを使用します。
4. 対象ユーザー名と新しいパスワードを入力します。
5. そのユーザー名が既に存在する場合、FileUni は確認後にそのユーザーを管理者へ昇格し、パスワードを更新します。

## 例

ランタイムディレクトリが `/srv/fileuni` の場合、次を実行できます：

```bash
fileuni --runtime-dir /srv/fileuni reset-admin --user admin --password admin888
```

`admin` が存在しない場合、このコマンドは管理者を作成します。

そのユーザー名が既に存在していて管理者ではない場合、確認後に昇格とパスワード更新を行えます。

## 重要な注意事項

- 回復しているデプロイと同じランタイムディレクトリを使用してください。
- 異なるランタイムディレクトリを指定すると、誤って別のデプロイを初期化する可能性があります。

## トラブルシューティング

### コマンドが正しいデプロイを変更しない

以下の項目を確認してください：

- `-R/--runtime-dir` で渡したランタイムディレクトリが正しい
- `config.toml` 内のデータベース接続が対象デプロイを指している

### ランタイムディレクトリがわからない

以下から回復できます：

- サービスインストールコマンドまたはサービスマネージャー
- デスクトップアプリのランタイムディレクトリ選択
- スタートアップスクリプトまたはシェル履歴
