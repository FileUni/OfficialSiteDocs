# 重置管理員密碼

如果您丟失了管理員密碼，當前受支援的恢復方式是明確執行管理員重置操作。

## 恢復步驟

1. 停止正在執行的 FileUni 服務或桌面程式。
2. 找到當前部署的執行目錄。
3. 執行管理員重置命令，或開啟桌面啟動器中的“修改管理員密碼”。
4. 輸入目標使用者名和新密碼。
5. 如果該使用者名已存在，系統會提示是否繼續，並在確認後把該使用者提升為管理員並更新密碼。

## 示例

如果您的執行目錄是 `/srv/fileuni`，可以執行：

```bash
fileuni --runtime-dir /srv/fileuni reset-admin --user admin --password admin888
```

如果 `admin` 不存在，命令會建立管理員。

如果該使用者名已存在但不是管理員，命令會在確認後提升該使用者為管理員並更新密碼。

桌面版可以開啟 `fileuni-gui`，在啟動器的設定選單中選擇“修改管理員密碼”，填寫使用者名與新密碼後提交。

## 重要說明

- 恢復時必須使用和原部署相同的執行目錄。
- 如果指向了另一組執行目錄，您可能會誤初始化另一套部署。

## 故障排除

### 命令執行後沒有修改到目標部署

請檢查：

- `-R/--runtime-dir` 指向的執行目錄是否正確
- 當前設定檔裡的資料庫連線是否就是目標部署使用的資料庫

### 我不知道執行目錄在哪裡

可以從這些位置反查：

- 系統服務安裝命令或服務管理器
- 桌面程式裡之前選擇過的執行時目錄
- 啟動指令碼或 Shell 歷史記錄
