# 重置管理员密码

如果您丢失了管理员密码，当前受支持的恢复方式是显式执行管理员重置操作。

## 恢复步骤

1. 停止正在运行的 FileUni 服务或桌面程序。
2. 找到当前部署的运行目录。
3. 执行管理员重置命令，或打开桌面启动器中的“修改管理员密码”。
4. 输入目标用户名和新密码。
5. 如果该用户名已存在，系统会提示是否继续，并在确认后把该用户提升为管理员并更新密码。

## 示例

如果您的运行目录是 `/srv/fileuni`，可以执行：

```bash
fileuni --runtime-dir /srv/fileuni reset-admin --user admin --password admin888
```

如果 `admin` 不存在，命令会创建管理员。

如果该用户名已存在但不是管理员，命令会在确认后提升该用户为管理员并更新密码。

桌面版可以打开 `fileuni-gui`，在启动器的配置菜单中选择“修改管理员密码”，填写用户名与新密码后提交。

## 重要说明

- 恢复时必须使用和原部署相同的运行目录。
- 如果指向了另一组运行目录，您可能会误初始化另一套部署。

## 故障排除

### 命令执行后没有修改到目标部署

请检查：

- `-R/--runtime-dir` 指向的运行目录是否正确
- 当前配置文件里的数据库连接是否就是目标部署使用的数据库

### 我不知道运行目录在哪里

可以从这些位置反查：

- 系统服务安装命令或服务管理器
- 桌面程序里之前选择过的运行时目录
- 启动脚本或 Shell 历史记录
